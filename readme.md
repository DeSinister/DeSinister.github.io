# Nishq Desai | Portfolio

Personal portfolio site for [desinister.github.io](https://desinister.github.io).

## Stack

Static HTML, CSS, and JavaScript, deployed via GitHub Pages.

## Local preview

```bash
cd Portfolio
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Structure

- `index.html` page content
- `style.css` design system and layout
- `script.js` nav, scroll reveal, mobile menu
- `assets/` SVG marks and icons
